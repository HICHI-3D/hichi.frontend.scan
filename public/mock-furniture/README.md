# mock-furniture

졸전 배너/시연용 가구 mock 사진.

다음 파일명으로 떨궈주세요 (확장자 .png / .jpg / .webp 아무거나 OK,
코드에서는 `.png` 로 참조 중이라 파일명만 맞춰주면 됨):

- `bed.png`   — 침대 카드 / 데모 결과 화면용 침대 사진
- `chair.png` — 의자 카드 / 데모 결과 화면 "원본 사진" 용 라운지 의자 사진

권장:
- 배경 제거 (투명) PNG 가 가장 깔끔 (card 배경이 살짝 회색이라 검정 bg 그대로면 튐).
- 가로:세로 비율은 카드(정사각형) / 데모(4:3) 모두 `object-cover` 라 자르긴 함.
- 파일 크기는 압축해서 300KB 이하 권장.

파일을 떨구면:
- `App.tsx` 의 `furnitureItems` 중 `퀸 침대` / `싱글 침대` / `라운지 의자` /
  `사무용 의자` 카드가 자동으로 사진을 띄움.
- `ScanResultDemo` 의 "원본 사진" 카드도 chair.png 를 우선 사용 (없으면 기존 SVG).

파일이 없으면 카드는 카테고리 SVG 일러스트로 fallback — 깨지지 않음.
